تحديث إدارة المخدومين والحضور والافتقاد
=====================================

محتويات الحزمة:
- client/src/App.tsx : نموذج ملف المخدوم وشاشة الحضور والافتقاد.
- client/src/style.css : تنسيقات الشاشات الجديدة.
- server/src/routes.js : توسيع واجهات API لحفظ حقول ملف المخدوم والافتقاد.
- database/migration_002_child_profiles.sql : ترقية آمنة لقاعدة البيانات بإضافة أعمدة فقط.

طريقة التركيب:
1) أوقف التطبيق من نافذة التشغيل باستخدام Ctrl+C.
2) خذ نسخة احتياطية من مجلد client ومجلد server وقاعدة البيانات.
3) انسخ محتويات client وserver إلى المجلدات المناظرة داخل المشروع، مع استبدال الملفات المطلوبة.
4) نفّذ ترقية قاعدة البيانات مرة واحدة من PowerShell:
   cd D:\service-management-app-v1\service-management-app
   & "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U service_app -h 127.0.0.1 -p 5432 -d service_management -W -v ON_ERROR_STOP=1 -f ".\database\migration_002_child_profiles.sql"
5) شغّل من جذر المشروع:
   npm run build
6) إذا نجح البناء:
   npm run dev

ملاحظات:
- الترقية تضيف أعمدة ولا تحذف بيانات حالية.
- لا يوجد رفع صور للمخدومين بعد؛ photo_path محجوز للتطوير اللاحق.
- تاريخ الميلاد محفوظ ميلاديًا حاليًا؛ عرض التاريخ القبطي لم ينفذ بعد.
- لا تزال المزامنة دون إنترنت غير مفعلة.
- سجلات الحضور والافتقاد تُحفظ لكل مخدوم وتاريخ. حالات الافتقاد: لا يحتاج، مطلوب افتقاد، تم التواصل، اكتملت المتابعة.
- اختبر على بيانات تجريبية أولًا، ولا تستخدم بيانات أطفال حقيقية قبل استكمال اختبارات الأمان والنسخ الاحتياطي.
