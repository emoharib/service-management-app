# نظام إدارة الخدمة — النسخة التأسيسية 1.0

تطبيق ويب عربي قابل للتثبيت (PWA) مع واجهة React/Vite وواجهة API مبنية بـ Express وقاعدة PostgreSQL.

## الموجود في هذه النسخة
- تسجيل دخول بالبريد الإلكتروني أو الهاتف.
- ثلاثة أدوار: `admin` مدير النظام، `service_manager` مسؤول الخدمة، `class_servant` خادم فصل.
- خادم الفصل مربوط بفصل واحد، وتتحقق واجهة API من الفصل عند قراءة بيانات الأولاد والحضور وعند الإضافة.
- صلاحية تسجيل الحضور لخادم الفصل منفصلة عن دوره، ويمكن منحها أو منعها من مدير النظام عند إنشاء الحساب.
- كلمات المرور مخزنة باستخدام bcrypt، ورموز الجلسات JWT مدتها 8 ساعات، مع تحديد محاولات تسجيل الدخول.
- PostgreSQL مع استعلامات مجهزة parameterized queries.
- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر.
- تخزين ملفات واجهة التطبيق الأساسية مؤقتًا لتسهيل فتح الغلاف بعد زيارة سابقة.

## ما لم يكتمل بعد — مهم
هذه ليست نسخة إنتاجية ولا تحقق حتى الآن العمل الكامل دون إنترنت. التخزين المحلي للبيانات الحساسة، وتسجيل الدخول دون اتصال، وطابور المزامنة وحل تعارض التعديلات لم تُفعّل. مسار `/sync` يرجع 501 عمدًا ولا يطبق أي بيانات. كذلك عرض التاريخ القبطي والميلادي، وإدارة الحضور التفصيلية، والنسخ الاحتياطي الآلي، وسياسات PostgreSQL الإضافية، واختبارات التكامل لم تكتمل. لا تدخل بيانات أطفال حقيقية قبل إكمال هذه المراحل.

## المتطلبات
- Node.js 20 أو أحدث (بيئة التطوير الحالية لدى المستخدم Node 26).
- PostgreSQL 16 أو أحدث.
- Windows PowerShell أو Terminal.

## تشغيل محلي على Windows PowerShell
من داخل مجلد المشروع:

1. أنشئ قاعدة البيانات من pgAdmin أو باستخدام psql:

```powershell
createdb -U postgres service_management
psql -U postgres -d service_management -f .\database\schema.sql
```

2. أنشئ ملف إعدادات السيرفر:

```powershell
Copy-Item .\server\.env.example .\server\.env
notepad .\server\.env
```

عدّل `DATABASE_URL` بكلمة مرور PostgreSQL الفعلية، وضع قيمة عشوائية طويلة في `JWT_SECRET` (32 حرفًا على الأقل). اترك `CLIENT_ORIGIN=http://localhost:5173` للتطوير المحلي.

3. ثبّت الحزم وشغّل:

```powershell
npm install
npm run dev
```

الواجهة: http://localhost:5173
الخادم: http://localhost:4000/health

4. في نافذة PowerShell ثانية، أنشئ أول مدير نظام:

```powershell
npm run create-admin -w server
```

سيطلب الاسم والبريد وكلمة المرور. لا توجد حسابات افتراضية.

## فحوصات
```powershell
npm test
npm run build
```
اختبارات `npm test` الحالية اختبارات وحدات بسيطة لوسيط الصلاحيات، وليست بديلًا عن اختبار API فعلي بحسابات وقاعدة بيانات.

## قواعد أمان قبل النشر
- لا تعرض PostgreSQL للإنترنت ولا تفتح منفذه في الراوتر.
- لا تنشر الخادم للعامة قبل اختبار عزل كل فصل بحسابات فعلية.
- استخدم HTTPS ونفقًا آمنًا مثل Cloudflare Tunnel عند تجهيز الوصول الخارجي، مع حماية إضافية مناسبة.
- جهّز نسخًا احتياطية مشفرة واختبر الاستعادة.
- انقل ملف `.env` بطريقة آمنة ولا تضعه داخل الحزمة أو Git.
